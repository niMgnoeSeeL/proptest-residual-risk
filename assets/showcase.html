What a passing proptest run tells you

The same test, run without and with proptest-residual-risk
proptest
proptest + proptest-residual-risk
$ cargo test test clamp_in_range ... ok
$ RESIDUAL_RISK=1 cargo llvm-cov --no-report \ -- --test-threads=1 --nocapture proptest: 256 passing test cases ... coverage: 9 of 12 regions (75%) in the code under test new code: about 0.0039 chance per test case failure: at most 0.012 chance per test case (95% confidence) ... test clamp_in_range ... ok
coverageregions of the code under test that the 256 test cases ran
new codeestimated chance that the next test case runs a region none has run
failureupper bound (95%) on the chance that the next test case fails
All three are about inputs from the test's own generator.crates.io/crates/proptest-residual-risk
